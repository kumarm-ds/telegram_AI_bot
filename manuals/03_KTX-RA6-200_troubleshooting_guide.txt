----------------------------------------------------------------------

This guide lists diagnostic codes for the KTX-RA6-200. All codes use the prefix RA6.

1. ERROR CODE REFERENCE

  RA6-011: Joint 3 servo drive over-temperature.
  RA6-045: Emergency stop circuit open — check E-stop loop continuity.
  RA6-088: Collision detection triggered on Joint 5.
  RA6-120: Teach pendant communication timeout.
  RA6-156: Brake release fault on Joint 2 — verify 24V brake supply.

2. GENERAL DIAGNOSTIC PROCEDURE

  1. Note the exact error code shown on the display/HMI.
  2. Check the corresponding entry in Section 1 above.
  3. Isolate power before inspecting any electrical component.
  4. If the fault recurs after a reset, contact Kaltrix Technical Support and quote the error code and unit serial number.
  5. Do not bypass any safety interlock to clear a fault.

3. WHEN TO ESCALATE TO A SERVICE ENGINEER

  Escalate immediately if: the fault repeats more than twice within an hour, any burning smell is present, or the error code is not listed above. Reference the KTX-RA6-200 Warranty Terms document before authorizing any third-party repair, as unauthorized repair may void coverage.
