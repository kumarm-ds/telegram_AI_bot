Troubleshooting Guide
Product Line: Plastics Processing Machinery
Model: KTX-IM1200

----------------------------------------------------------------------

This guide lists diagnostic codes for the KTX-IM1200. All codes use the prefix IM.

1. ERROR CODE REFERENCE

  IM-501: Barrel zone 2 heater fault — check thermocouple TC-2.
  IM-518: Mold safety door interlock not confirmed.
  IM-533: Injection pressure sensor drift beyond tolerance.
  IM-547: Hydraulic oil temperature high — check cooler flow.
  IM-560: Screw recovery time exceeded set threshold.

2. GENERAL DIAGNOSTIC PROCEDURE

  1. Note the exact error code shown on the display/HMI.
  2. Check the corresponding entry in Section 1 above.
  3. Isolate power before inspecting any electrical component.
  4. If the fault recurs after a reset, contact Kaltrix Technical Support and quote the error code and unit serial number.
  5. Do not bypass any safety interlock to clear a fault.

3. WHEN TO ESCALATE TO A SERVICE ENGINEER

  Escalate immediately if: the fault repeats more than twice within an hour, any burning smell is present, or the error code is not listed above. Reference the KTX-IM1200 Warranty Terms document before authorizing any third-party repair, as unauthorized repair may void coverage.
