This guide lists diagnostic codes for the KTX-HP4520. All codes use the prefix HP.

1. ERROR CODE REFERENCE

  HP-101: Reservoir oil level below minimum threshold (sensor LS-1).
  HP-114: Oil temperature exceeded 68°C — thermal cutoff triggered.
  HP-207: Pressure transducer PT-2 signal out of range (0.2-4.8V expected).
  HP-233: Main drive motor overload — check for downstream valve blockage.
  HP-309: Return line filter differential pressure exceeds 3.5 bar — replace element.

2. GENERAL DIAGNOSTIC PROCEDURE

  1. Note the exact error code shown on the display/HMI.
  2. Check the corresponding entry in Section 1 above.
  3. Isolate power before inspecting any electrical component.
  4. If the fault recurs after a reset, contact Kaltrix Technical Support and quote the error code and unit serial number.
  5. Do not bypass any safety interlock to clear a fault.

3. WHEN TO ESCALATE TO A SERVICE ENGINEER

  Escalate immediately if: the fault repeats more than twice within an hour, any burning smell is present, or the error code is not listed above. Reference the KTX-HP4520 Warranty Terms document before authorizing any third-party repair, as unauthorized repair may void coverage.
