This guide lists diagnostic codes for the KTX-WS210. All codes use the prefix WS.

1. ERROR CODE REFERENCE

  WS-301: Wire feed motor stall detected.
  WS-315: Gas flow sensor reading below 4 L/min threshold.
  WS-322: Torch trigger circuit fault.
  WS-340: Output thermal protection engaged — cool-down required.
  WS-355: Primary contactor fault — check K1 relay.

2. GENERAL DIAGNOSTIC PROCEDURE

  1. Note the exact error code shown on the display/HMI.
  2. Check the corresponding entry in Section 1 above.
  3. Isolate power before inspecting any electrical component.
  4. If the fault recurs after a reset, contact Kaltrix Technical Support and quote the error code and unit serial number.
  5. Do not bypass any safety interlock to clear a fault.

3. WHEN TO ESCALATE TO A SERVICE ENGINEER

  Escalate immediately if: the fault repeats more than twice within an hour, any burning smell is present, or the error code is not listed above. Reference the KTX-WS210 Warranty Terms document before authorizing any third-party repair, as unauthorized repair may void coverage.
