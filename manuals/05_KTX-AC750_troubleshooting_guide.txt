This guide lists diagnostic codes for the KTX-AC750. All codes use the prefix AC.

1. ERROR CODE REFERENCE

  AC-201: Discharge air temperature exceeded 105°C.
  AC-215: Oil separator differential pressure high — replace element.
  AC-230: Inlet valve actuator fault.
  AC-244: Phase imbalance detected on main motor supply.
  AC-260: Condensate drain valve blocked — check auto-drain KTX-AC-DRN1.

2. GENERAL DIAGNOSTIC PROCEDURE

  1. Note the exact error code shown on the display/HMI.
  2. Check the corresponding entry in Section 1 above.
  3. Isolate power before inspecting any electrical component.
  4. If the fault recurs after a reset, contact Kaltrix Technical Support and quote the error code and unit serial number.
  5. Do not bypass any safety interlock to clear a fault.

3. WHEN TO ESCALATE TO A SERVICE ENGINEER

  Escalate immediately if: the fault repeats more than twice within an hour, any burning smell is present, or the error code is not listed above. Reference the KTX-AC750 Warranty Terms document before authorizing any third-party repair, as unauthorized repair may void coverage.
